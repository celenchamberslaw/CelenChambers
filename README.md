# Celen Chambers – International Law Firm

Welcome to the **Celen Chambers** website source code. This project is a clean, static web site built with vanilla HTML, CSS, and JavaScript—no frameworks or build tools.

## Project Overview

- **Technology Stack:** HTML5, CSS3 (custom design system), vanilla JavaScript.
- **Pages:** Home, Practice Areas, Our Lawyers, Online Security, Contact Us.
- **Features:**  
  - Responsive design with mobile navigation.  
  - Smooth scroll‑triggered animations using CSS and Intersection Observer.  
  - Multi‑language support (i18n JSON files).  
  - Contact form integrated with Resend API (backend endpoint required).  
  - Professional lawyer portrait images, including a newly generated high‑end headshot.

## Development

1. Open the project folder in any code editor.  
2. Serve the `web` directory with a simple static server (e.g., `python -m http.server` or VS Code Live Server).  
3. Edit HTML/CSS/JS directly; changes are reflected instantly thanks to the lightweight architecture.

## Assets

- Images are stored in `web/images/`.  
- The main lawyer portrait (`lawyer.jpg` and `partner-portrait-1.jpg`) has been updated to a premium corporate headshot.
